# lunarcit0’s Math Lab

Four course practice sections, free graphing and arithmetic. Standalone guided Function Lab has been removed; quiz-specific visuals and Free Graphing remain. Arithmetic includes fraction-to-decimal conversion, decimal-to-simplified-fraction conversion, and addition/subtraction/multiplication/division of fractions. Repeating decimals may be rounded to 4 or more decimal places. Equivalent fractions are accepted for operations; decimal-to-fraction conversion requires simplest form.

Upload all files, preserving assets/. Open index.html locally or use GitHub Pages. No packages/build required.
