# Modulo Quest

Hey so i used chat for most of this game. I made it so I could understand Modulo Arithmetic (not ashamed) feel free to play. anyway I'll let chat explain it to you. Best - Lunarcit0

## Run locally
Open index.html in your browser. No installation or build step is required.

## Files
- index.html: page structure
- style.css: appearance and responsive layout
- game.js: questions, scoring, hints, and dot visualizations

## Save to GitHub
1. Create a repository named modulo-quest, or open a repository where you want this project.
2. Extract this ZIP file.
3. Use GitHub's file upload option to upload the extracted files together, preserving their names, then commit.

To host with GitHub Pages, keep index.html, style.css, and game.js together at the repository root. In repository Settings > Pages, choose Deploy from a branch, then select your branch and / (root), and save.
